## 이 배포 ZIP 데이터의 시점

현재 ZIP은 이전 D1 배포본의 사본으로, 내장된 기존 정책별 CSV의 결과는 legacy 75%, YOLO 95%, Haar 50%, improved 85%입니다. **위 최신 70/80/55/80% 실행 결과 CSV 또는 신규 자동 백업 폴더의 실제 파일은 이 ZIP에 포함되어 있다고 주장하지 않습니다.** 최신 결과의 영구 보관이 필요하면 사용자 PC에서 해당 `outputs` 및 `csv_backup`을 별도 보관해야 합니다.

## A 단계에서 재실행한 자동 테스트

- `python -m unittest discover -s tests -p test_d1_integration.py -q`: **11개 통과**
- `python -m pytest tests/test_main_1.py -q`: **6개 통과**
- 이 환경에서 실제 YOLO 가중치를 재추론하지 않았습니다. 사용자 Windows 실행 로그로 실환경 추론을 확인했습니다.

## 남은 검증과 제한사항

1. 실제 저장 자료로 복원 작업을 수행한 Windows 환경 종단 간 검증은 아직 없음(모의 복원 테스트는 통과).
2. 수동 검수 CSV 입력 후 Windows에서 재분석하여 보존되는지 실환경 시험은 미확인(자동화 테스트는 통과).
3. 실제 얼굴 위치의 정답 박스 및 모자이크 품질은 별도로 수동 검수해야 함. 얼굴 개수 일치율을 비식별화 성공률로 표현하지 않음.
4. `python source/main_1.py --compare` 직접 실행은 실행 전 백업 질문을 우회하므로 공식 실행 명령을 사용해야 함.
5. 사용자 PC에서 생성된 최신 실험 결과는 아직 이 배포 ZIP에 동기화하지 않음.
