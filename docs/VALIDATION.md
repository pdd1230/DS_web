# 검증 결과

검증일: 2026-11-07. 생성 환경은 Linux이며 Python 3.11.9, CPU PyTorch 2.6.0, OpenCV 4.11.0, Ultralytics 8.3.112를 사용했다. Java는 JDK17, Spring Boot4.0.9, Gradle8.14.3이다.

## 실제 수행

|항목|결과|증거·범위|
|---|---|---|
|Python 계약·내부 API·기존 원본 테스트|24개 통과|tests + legacy/tests|
|Java 테스트·컴파일·bootJar|4개 테스트 통과|Gradle 실제 빌드·HTTP 통합시험 포함|
|Spring 기동·마이그레이션·저장 스키마 검사|통과|H2 MySQL 호환 모드에서 실제 실행|
|Spring HTTP → Python API → 실제 모델 → DB 수집|통과|기준 사진20장, 4정책 결과80행|
|수동 검수 저장·분석 재실행|통과|HTTP 저장, 추론 없이 새 보고서 개정, 결과 중복 없음|
|보고서 ZIP 다운로드|통과|실제 HTTP 응답과 ZIP 크기 확인|
|초기·기준 프로그램 실행|통과|각20장 실제 실행·결과 이미지/평가 정규화. 초기 프로그램은 Spring 통합 경로도 확인|
|새 실험 실행 시 이전 결과 보존|통과|첫 실험 매니페스트 해시 불변·보존 참조 생성|
|과거 4정책·초기·기준 결과 가져오기|통과|각80/20/20행, 초기 과거 개수 미확인 유지|
|기존 공식 CLI와 어댑터 회귀 비교|통과|동일 환경·사진·모델·기본 설정에서 추론 CSV16개 전체행 일치 + 결과 이미지80개 SHA256 일치|
|정답표 중복·누락·음수·이름 충돌|통과|실행 전 거절 테스트|
|경로 이탈·잘못된 내부 키|통과|단위/API 시험|
|변조된 산출물 해시 검증|통과|실제 파일 수정 후 거절 시험|
|프런트 JavaScript 구문|통과|node --check|

기존 Java JUnit 통합시험은 H2 전용 프로필을 사용한다. 이후 별도 MySQL 8.4.11 서버와 운영용 bootJar를 사용해 실제 MySQL 마이그레이션·추론 저장·서버 재시작·백업 복원까지 검증했다. 운영 application.yml은 MySQL 전용이며 연결 실패 시 다른 DB로 자동 전환하지 않는다.

이번 CPU 실행의 4정책 개수 일치율은 legacy75%, yolo_only95%, haar_only50%, improved85%였다. 이는 이 기준 사진20장과 해당 환경의 결과다. 개수 일치율을 얼굴 위치 정확도·비식별화 품질·다른 데이터셋 성능으로 해석하지 않는다.

## 이어서 수행한 추가 검증

|항목|결과|범위|
|---|---|---|
|MySQL 8.4.11 Flyway·Hibernate 스키마 검증|통과|실제 MySQL 서버, 애플리케이션 테이블10개 + Flyway 테이블1개|
|운영 bootJar → Python → 실제 추론 → MySQL|통과|기준 사진20장·4정책80행|
|MySQL 검수·보고서 개정 저장|통과|검수1건·보고서2개|
|Spring 서버 재시작 후 조회|통과|결과80행·검수1건·보고서2개 유지|
|실제 mysqldump·별도 DB/파일 경로 복원|통과|복원한 서버에서 DB 기록·동일 이미지·ZIP 조회|
|PowerShell 스크립트7개 구문 검사|통과|PowerShell7.4.13 / Linux. Windows 실행과 구분|
|백업 경로·매니페스트 보완|통과|상대/공백 경로, 기존 폴더 거절, storage 내부 백업 거절. 파일 계약 시험의 dump 명령은 모의 처리|

추가 MySQL 검증은 사용자 PC가 아닌 격리된 Linux 환경에서 수행했다. PowerShell 계약 시험의 모의 dump와 별개로, MySQL 덤프·복원 시험에는 실제 mysqldump/mysql 명령을 사용했다.

## 사용자 PC 합격 확인

1. README 순서대로 전용 DB와 가상환경을 준비한다.
2. 통합 시작 후 기준 사진20장을 등록하고 4정책 실험을 완료한다.
3. 로그·정답·정책별 결과·오답 표·후보 좌표를 확인한다.
4. 검수1건을 저장하고 보고서 r2를 생성한다. r1과 원본이 유지되는지 확인한다.
5. 초기·기준 프로그램도 새 실험으로 실행한다.
6. 앱 종료·재시작 후 같은 실험·이미지·검수·보고서가 조회되는지 확인한다.
7. 백업 후 별도 DB·경로에 복원해 조회한다.

테스트 로그와 회귀 비교 요약은 `docs/verification/`에 포함한다. 위 미확인 항목은 통과로 소급하지 않는다.
