# 프로젝트 진행 상태 재점검

점검일: 2026-11-07

## 확인 결과

기존 프로젝트 코드는 작성·빌드·검증·ZIP 제공까지 완료되어 있었다. 중단된 소스 생성이나 실패 상태의 최종 빌드는 발견하지 않았다. 기존 ZIP의 릴리스 매니페스트262개 파일과 Java 테스트4개 성공 기록, CSV16개·이미지80개 회귀 비교 기록을 확인했다.

## 완료한 작업

- 사진·정답표 버전 관리, 프로그램 선택·실행, 상태·로그 조회.
- 초기 Haar·YOLO+Haar 기준·4정책 비교·분석만 재실행.
- 이미지 비교·오답 분석·수동 검수·보고서 개정·이력·다운로드.
- Python24개 테스트, Java4개 테스트, 실제 모델 추론·공식 CLI 비교.
- Gradle Wrapper, MySQL SQL, 설치·시작·종료·점검·백업 도구, 설계·실행 문서.

## 이번에 이어서 완료한 작업

1. 실제 MySQL8.4.11에서 Flyway 마이그레이션과 Hibernate 스키마 검증.
2. 운영용 Spring Boot JAR와 Python3.11.9를 통한 사진20장·4정책80행 저장.
3. 검수1건·보고서2개 생성, 이미지와 ZIP 다운로드.
4. Spring 재시작 뒤 결과·검수·보고서 유지 확인.
5. 실제 mysqldump와 storage를 별도 DB·경로로 복원하고 동일 이미지·기록 조회.
6. PowerShell7.4.13으로 스크립트7개 구문 검사.
7. Backup.ps1의 상대/공백 경로 매니페스트 수정, storage 내부 재귀 백업 방지, 빈 덤프 검사.
8. 보완한 백업 파일 동작 시험과 검증 문서·배포 ZIP 갱신.

## 남은 작업

|항목|남은 이유·다음 확인|
|---|---|
|사용자 Windows에서 Setup/Start/Stop/Test 전체 실행|이 세션에서 사용자 Windows를 직접 실행할 수 없음. 실제 JDK·Python·MySQL 계정·PATH 확인 필요|
|Windows Backup.ps1과 실제 장치 복원|Linux MySQL 복원은 통과했으나 Windows 명령·경로·장치 조합은 별도 확인 필요|
|브라우저 전체 화면·키보드·반응형 조작|현재까지 HTTP API·화면 제공·JS 구문을 검증했고 전체 브라우저 자동조작은 미실시|
|얼굴 품질 전체 수동 검수|모델의 개수 일치와 실제 비식별화 품질은 별도. 교사·학생의 확인 필요|
|장비 고장·전원 차단·동시 사용자 부하|초기 로컬 사용 범위에서 실제 장애·부하 시험 미실시|

웹캠·동영상·비전 에이전트·새 모델 학습은 기존 승인 계획상 별도 확장이다. 이번 구현의 중단 항목으로 분류하지 않는다.

## 사용자 PC에서 이어갈 첫 순서

1. 보완 ZIP을 새 폴더에 풀고 README에 따라 환경을 준비한다.
2. 전용 DB를 생성하고 config.ps1에 실제 접속 정보를 입력한다.
3. Start.ps1 실행 후 기준 사진20장으로 프로그램을 실행한다.
4. 검수·보고서 갱신·재시작 조회를 확인한다.
5. 마지막으로 별도 장치에 백업·복원을 확인한다.
